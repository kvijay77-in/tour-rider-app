# Initial development planning – summary

_Last updated: 2026-09-29_

> Historical – kept for reference.

This note records the early planning phase of the rider app. Its original plan discussed a separate rider-pool deployment, a potential local reading mode and future multi-organizer flows; these are **not descriptions of the current app**. The rider pool and all AWS infrastructure belong to [tour-data-api](https://github.com/kvijay77-in/tour-data-api/blob/main/docs/guides/deployment.md). The rider app has no supported offline mode. Multi-organizer invitation discovery is not connected to current screens.

The early milestones included authentication and profiles, tours and ride views, check-in views, notifications and training. For verified current behavior see [requirements](../README.md), [architecture](../design/architecture.md) and the [rider guide](../user-guide/README.md).
