# Notifications

_Last updated: 2026-09-29_

- Home shows recent notifications. The drawer and header bell open the inbox; unread counts appear on the bell when notification service is available.
- Riders can view items; opening the inbox marks all notifications read. The app registers supported mobile devices for push notifications, subject to device and user permission; the inbox remains available without push permission.
- If notification endpoints report unavailable, the badge is hidden rather than displaying an error count.

See [notification design](../design/notifications.md). The backend [API reference](https://github.com/kvijay77-in/tour-data-api/blob/main/docs/design/api-reference.md) owns delivery and message contracts.
